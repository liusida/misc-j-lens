# Experiments

- `one_prompt/`: inspectable one-prompt J-Lens reproduction;
- `split_lenses/`: notes and prompt material for temporal target splits;
- `single_jacobian/`: single-context Jacobians versus trained lenses;
- `oscillation/`: downstream response and oscillation measurements;
- `token_patching/`: swimming, centuries, and war intervention cases;
- `case_studies/`: token-direction attribution and soccer/centuries studies;
- `decoding/`: legacy rendering and evaluation scripts;
- `pairwise/`: source/target-position Jacobian inspection;
- `legacy_split/`: superseded 25-prompt split-fitting experiments.

New supported fitting and decoding commands belong in `scripts/`. Shared
implementation code belongs in `src/jlens_study/`.
